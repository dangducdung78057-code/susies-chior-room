StageOS 全栈产品蓝图 v1

公开展示站 + 工作台 + 预览导出的一体化艺演助手

本站整理 StageOS 艺演助手的产品定位、页面结构、接口设计、运行方式与功能边界， 用于演示项目范围并支撑后续工程落地。

Next.js App Router + TypeScript PostgreSQL + Prisma ORM JWT Cookie 登录注册 2D / 3D / 插画 / 写实预览

核心能力

  • 艺案集案例展示与一键同款工作台
  • 素材上传、数据库存储、方案生成与 Negative Guard 审查
  • 2D 数字人、3D 交互预览、插画风与写实风提示词输出
  • 项目 JSON 导出与后续第三方服务扩展位保留

技术栈

  • Next.js App Router + TypeScript
  • PostgreSQL + Prisma ORM
  • 自研 JWT Cookie 登录注册
  • 本地文件上传存储，可替换对象存储
  • React Three Fiber / three.js 3D 预览
  • Zod 输入校验，支持可选 OpenAI Responses API 文本增强

本地运行

目标工程启动流程

cp .env.example .env
npm install
npx prisma generate
npx prisma migrate dev
npm run db:seed
npm run dev

默认种子账号：admin@stageos.local / StageOS123!

Docker 部署

容器化交付路径

cp .env.example .env
docker compose up --build

docker compose exec app npx prisma migrate deploy
docker compose exec app npm run db:seed

首次启动后完成迁移与种子，再访问 http://localhost:3000。

生产部署注意

上线前必须确认

  1. 修改 AUTH_SECRET。
  2. 多实例部署时将本地上传目录替换为对象存储。
  3. 如需 OpenAI 文本增强，配置 AI_PROVIDER、OPENAI_API_KEY 与 OPENAI_TEXT_MODEL。
  4. 插画/写实模式目前输出受约束提示词，可继续对接外部图像服务。
